# Pigeon Slash

A progressive pixel-art bird shooting game set in the Yorkshire Dales.
See [GAME_DESIGN.md](GAME_DESIGN.md) for the full design.

## Play

Open `index.html` in any modern browser — no build step, no server needed.

(Optionally serve it: `python3 -m http.server` then visit
`http://localhost:8000`.)

## Controls

| Input | Action |
|---|---|
| Mouse | Aim |
| Left click | Shoot |
| R | Reload |
| M | Mute |

On phones and tablets: tap the birds to shoot (with haptic feedback where
the device supports it); the gun reloads itself when empty. Landscape
orientation recommended.

Drop two birds with one shot for a **Brace Bonus**. Money and stats save
automatically in your browser.
